# Simpletron
Proyecto desarrollado en lenguaje C que simula el funcionamiento básico de una computadora Simpletron.

El programa utiliza una memoria de 100 posiciones y ejecuta instrucciones SML mediante registros como el acumulador, contador de instrucciones y código de operación.

## Archivos

- `Simpletron.c`: código fuente del programa.
- `Corrida Simpletron.pdf`: evidencia de la ejecución del simulador.
